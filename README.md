# Wallet User Guide — SafePal

Independent SafePal user-help project built with Next.js 16.2.12.

## Vercel
Import the repository/project into Vercel. The site automatically uses VERCEL_PROJECT_PRODUCTION_URL for canonical URLs.

For a custom domain, set:
NEXT_PUBLIC_SITE_URL=https://your-domain.example

## Security
This site must never collect recovery phrases, seed phrases, private keys, wallet passwords or PINs.
